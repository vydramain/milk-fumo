# Every block of a note

A paragraph is rv_font in the main text color. **Bold words are bright and one pixel thicker**, *italic words lean*, and a [link](https://example.com) is bright with a dotted brass underline. An unsafe [link](javascript:alert) stays plain text. Keys are keycaps: [Shift] + [Enter].

## A second-level heading

### A third-level heading

- a list item has a brass square;
- a long list item wraps under its own text, not under the square, when the tile is narrower than the line;
- **bold** and *italic* work inside items.

> A quote has a brass bar on its left and wraps like a paragraph.
