MILK-FUMO design system

Every component the site draws, drawn by the site's own modules in site/js/. A stage is a canvas with one component in it. The content of the tiles is the fixture folder content/, read through a network you can slow down. A stage you click takes the keys, as a tile does.

Open the page from a static server started in the repository root, for example python3 -m http.server 8000, then go to localhost:8000/docs/design-system/. ES modules do not load from file://.

Scale Network

Scale is device pixels per layout pixel, the site's UI scale. Slow gives files at 32 KB/s, Stalled holds every file at 40 % until the network changes, Offline fails every request. A change of network affects new and running downloads; Restart opens every stage again with the current settings.

Foundations

Palette

The editor's tokens with vgui2-deck's state colors for the olive surfaces, and Catppuccin Mocha for the navy wells: players, apps, code. theme.js.

Type

All text is drawn from bitmap tables, never by the browser. rv_font is the interface and the note text; PxPlus IBM VGA is the text in the navy wells, at its native size or exactly twice it. Bold widens every run by one font pixel, italic shifts the upper half one pixel right. font.js, font_data.js, Paint.text.

Kind codes

File icons are two-letter codes in a color per kind. catalog.js: KIND.

Metrics

The sizes in layout pixels, read from metrics.js itself.

UI scale

The same bar at 1x, 1.5x and 2x, whatever the page's scale. At 1.5x a font pixel is one or two device pixels, so letters come out uneven; that is the known cost of 1.5x.

Primitives

paint.js: every rectangle is snapped to whole device pixels and nothing is smoothed.

Bevels and frames

Paint.bevel: light on the top and left, dark on the bottom and right, swapped when sunken. widgets.js: box, panelFrame, wellFrame are built from it.

Dithers

Paint.dither: a one-pixel checkerboard of two colors, and where each pair is used.

Slant

Pictures

Widgets

widgets.js: immediate-mode widgets. A widget draws itself and adds its rectangle to the frame's hit list in the same call.

Scroll bar

Arrows at both ends, a dithered track, a thumb no shorter than 8 px. A click on an arrow moves one item; a press on the track jumps and drags.

Load bar

A 37 x 11 sunken well with a dithered brass fill of floor(share × 35) px. The word is bright over the empty part and dark over the fill. done is full, errr empty.

Key bar

Cells of equal width, the key in a dark box and its name. A cell sinks while one of its keys is held, but only with its own modifiers: a Shift cell with Shift, any other without. Click the stage and hold keys to see the bars sink. The player and video bars never cut a name: they wrap into as many rows as it takes (keyRows), and the captions give the row count at the minimum widths and at 440 and 700 px. The other bars stay one row, and a name that does not fit is cut to two letters. The cells here are a copy of the ones the tiles build; each tile's own bar is on its stage under Tiles.

Foot panel

The file's line, the load bar, and the keyboard field: Keyboard: app in brass while an app has the keys.

Screens

What replaces the workspace on a screen under 960 x 540. widgets.js: messageScreen, chosen by main.js. A touch-first device gets the pocket version: pocket design system.

Error screen

The stub of a bad link or an nginx error page (the table of codes in texts.js: ERRORS): the code's name on the title plate, the code in VGA 2x, the line, and one key cell, Enter Return to /, which leads to the start screen. widgets.js: errorScreen, chosen by main.js. One stage per code, then the two link lines that name the file. Click a stage and hold Enter to see the cell sink; a click does nothing here but redraw.

Workspace

workspace.js on a layout tree from layout.js. These stages are real workspaces: click to focus, drag a title bar or a border, press X or M.

Tiles, title bars and tabs

A raised frame, the brass ring around the focused tile, the dithered title bar with X on the left and M on the right, the title cut to the bar. Tabs are slanted folder tabs at the bottom; the front one is brass.

Maximized

Drop preview

While a title bar is dragged, the place it would land is dithered brass: half of a tile near its edge, the whole tile in its middle or on its tabs.

Message line and environment bar

Always at the bottom. Every cell is a button. A cell sinks while Shift and its key are held, with Ctrl only for Move. Resize and Move stay sunk while their mode is on. The four bars: a message; Shift+R held; Ctrl+Shift+Left held; the resize mode.

Browser tab

The favicon Mf is the M button of the title bar, made by tools/favicon.js. The tab's title follows the focused tile: its app name.

Share links

A link is /?open=<path under the content root>. Each row runs the site's own catalog.js: linkPath on a query string, and linkOf on a good path: the path it opens, or the code of the error stub; and the address the tile then writes. A broken link sends no request.

Tiles

Each tile body alone, as the workspace draws it inside a tile.

pmc

pmc.js. Two panels, the path in each panel's top frame, brass on the active one. The cursor is brass in the focused tile's active panel. Click the stage, then use the arrows, Tab, letters, F3, Enter, Esc and Ctrl+PgUp. Opening a file in its own tile needs a workspace: try that in Environment.

F3 quick views: an image; a track with its player; a video; a note; a file without a viewer; a folder's information (an app's folder shows the same).

A folder that cannot be read (left) and a search by letters (right, mu); then a tile that is not focused, with an empty folder.

Note

note.js, markdown.js. Every block a note supports, and the tutorial's table: the first two actions are done, the third is the next. A narrow tile lists each action's ways under it and gets a scroll bar. A note that cannot be loaded says so.

Player

media.js, tags.js. The header from ID3v2 or Vorbis tags (the third track has none), the folder's name, the position, the volume, the playlist with a load bar per row, and the key bar: P Prev, Space Play (one cell, Pause while playing), S Stop, N Next, M Mute, <- -> Seek, ^ v Volume, wrapped into rows when the tile is narrow. missing.mp3 ends in errr once you select it.

Video

The player's top and the frame, which always fits the tile and fills down to the key bar; the same cells as the player, with L Loop before Seek and Shift+F Full last. The file's load bar ends the format line. Then the fullscreen: only the frame, and a panel with the position and the key bar that shows on a pointer move or a key and hides 3 s later with the cursor. Shift+F or a double click returns to the tile; here the stage stands in for the screen.

Image

image.js. A picture is shown at its own size or smaller, never enlarged. Left and Right go through the folder.

App

app.js. An iframe over the navy well, with a status line. The foot panel says Keyboard: app while the app runs in the focused tile; this stage draws its tile as focused. Click into the app to give it the keys (arrows push the square); Shift+0 inside it restarts it. A folder without index.html is an error.

Loading and messages

workspace.js: LoadingBody, MessageBody: a tile whose file is still coming, a file of a type without a viewer, a file that could not be loaded.

Motion

The site draws on events, not on a timer: a frame is drawn when something changes. Only a playing video asks for every animation frame. This is everything on the site that moves.
