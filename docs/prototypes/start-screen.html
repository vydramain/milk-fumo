How it works

The whole screen is divided into rectangular areas — tiles. Tiles never overlap: a new tile takes part of its neighbor's space, and a closed tile gives its space back. Each tile holds one thing: the file explorer, a player, a picture, a text or a game. Several tiles can be stacked into one — then tabs appear at its bottom, like the tabs on folders in a card file.

Mouse and keyboard

Everything here can be done with the mouse and with the keyboard. Use either one, or mix them — whatever suits you.

Choices made in this mockup

  • Interface font — rv_font 5×7 from pdklib, built into an OTF from the rv_font_data.hpp and rv_font_cyrillic.hpp tables. Scale 1, as in the screenshots; the site will need a scale setting, like View > UI Scale in the editor.
  • Markdown: headings — rv_font ×2 and ×1 with a dithered rule, as in the tile title bar; body — WineTahomaBit; code — PxPlus VGA on navy; keys — raised keycaps.
  • Navy wells (Catppuccin Mocha base, like Code and Game in the editor) — for the players and the app; the explorer and the notes are olive, like Files and Inspector.
  • Two-letter codes: from the editor — Fd, Sn, Im, Tx, Fi, Hm, Pl, Ps, Sp, Rs and their colors; new ones — Vi (video), Ap (app), Up, Pv, Nx, Mt.
  • Volume wheel and position scale — from the Scene tile (Rot X / Dolly / Rot Y). The selected-file line under the list — from Midnight Commander.
  • Getting the keyboard back from an app — for now by clicking another tile; a keyboard way is not decided.
