# milk-fumo v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the site to the 15 decided backlog items: app-name titles and favicon, readme + pmc start, load bars with
byte-counted downloads and preloading, clickable key bars in every tile, audio tags, video fullscreen, one tile per type
with the new F3/Enter rules, no manual splitting, UI scale 1.5x.

**Architecture:** Vanilla ES modules drawing an immediate-mode UI into one canvas (`Paint`, `Hits`). Three new pure
pieces carry the logic and are unit-tested in node: `download.js` (byte-counted fetch, per-tile cache), `tags.js`
(ID3v2 / Vorbis comment reader) and three widgets in `widgets.js` (load bar, key bar, foot panel). The tiles (`media.js`,
`image.js`, `note.js`, `app.js`, `pmc.js`) use them; `workspace.js` owns tile routing, titles, scale and fullscreen.

**Tech Stack:** Browser ES modules, Canvas 2D, Fetch + ReadableStream, Fullscreen API; tests with `node --test`
(Node ≥ 18: global `fetch`, `Response`, `ReadableStream`, `Blob`, `URL.createObjectURL`). No dependencies.

**Spec:** `docs/superpowers/specs/2026-11-04-milk-fumo-v3-design.md` (read it first; section numbers below refer to it).
Visual reference: `docs/prototypes/index.html` + `docs/prototypes/loader.css`.

## Global Constraints

- No new dependencies, no build step; `npm test` = `node --test tests/*.test.js` must stay green after every task.
- All sizes are whole layout pixels; colors only from `C` in `site/js/theme.js`.
- Every UI string lives in `site/js/texts.js` (`T`, `ENV_CELLS`, `TUTORIAL_ACTIONS`).
- Code comments, docs and commit messages in English, in the style of the existing files.
- Load bar words exactly `load`, `done`, `errr`; bar 37×11.
- Title bar texts exactly `pmc`, `Player`, `Video`, `Image`, `Note`, or the app's folder name.
- Scales exactly `[1, 1.5, 2]`.
- `dev/` is untracked: never `git add` anything under it.
- Commit only named files; one task = one commit, after its verification.
- Browser checks: `docker compose --env-file .env.dev up`, site at `http://localhost:8080`.

## Review Focus

1. Pressing N repeatedly while tracks download: each path is downloaded once, all started downloads finish → test in Task 2 (`want() twice returns the same Download`).
2. Closing a tile while its downloads run: no draw callbacks after close, object URLs revoked → test in Task 2 (`dispose aborts and revokes`).
3. A server response without Content-Length (gzip/chunked): bar stays `load` with share 0, then `done` → test in Task 2.
4. The window shrinks below 1.5x: the scale drops to the largest scale that still fits, not straight to 1 → test in Task 10.
5. The Player tile is closed, then Enter on a track: a new Player tile is made, no stale reference → test in Task 4.
