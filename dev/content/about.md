# О проекте

Это тестовая страница для среды разработки. Она проверяет, что Markdown выводится корректно.

Страница содержит несколько типовых элементов:

- заголовок первого уровня;
- абзац с текстом;
- список из трёх пунктов.

> Цитата нужна, чтобы проверить оформление блочных элементов.

Подробнее о домене можно прочитать на [example.com](https://example.com).
