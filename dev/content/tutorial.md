# How it works

Tiles are rectangles that never overlap. A new tile shares its space with the neighbor 1:1, and a closed tile gives its space back. Several tiles can stack into one, with tabs along its bottom. A tile can be maximized to the whole screen and restored. While a tile is moved, its future place is highlighted, and `Escape` cancels the move.

- Go to another tile: mouse - click it / keyboard - `Shift` + arrows
- Split a tile: mouse - the `│` `─` buttons in the title bar / keyboard - `Shift+H` beside, `Shift+V` below
- Open pmc: mouse - "pmc" in an empty tile / keyboard - `Shift+Enter`
- Move a tile: mouse - drag its title bar to the edge of another / keyboard - `Ctrl+Shift` + arrows
- Stack into tabs: mouse - drop its title bar onto the tabs / keyboard - `Shift+W`
- Resize: mouse - drag the border / keyboard - `Shift+R`, then arrows; `Enter` or `Esc` when done
- Fullscreen and back: mouse - `M` in the title bar / keyboard - `Shift+F`
- Close a tile: mouse - `X` in the title bar / keyboard - `Shift+Q`, also inside a game or app
